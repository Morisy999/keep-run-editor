# KEEPro 运动详情截图版

解压整个文件夹，用 Edge 或 Chrome 打开 `keep.html`。在编辑区设置个人资料和运动数据，点击“下载 PNG”即可保存当前预览。默认尺寸为 1260 × 2736，在“高级设置”中可调整导出宽度。

平均配速按“分.秒”填写，例如 4.54 表示每公里 4 分 54 秒。训练时长和消耗留空时按里程估算，总时长包含停留时间，用来计算结束时间。手动填写时长请使用 00:10:02 的格式。勾选“显示 PB 徽章”并填写最快配速即可显示金色徽章。取消勾选可隐藏徽章并保留成绩，点“保存偏好”可记住选择。

头像和地图可从本机选择，也可以手绘轨迹。点击“保存偏好”会将设置保存在当前浏览器。

基于 [KEEPro](https://gitee.com/joytion/keep/)。
